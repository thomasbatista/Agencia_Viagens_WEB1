# ✈️ Travel Agency — WEB1 Project (IFSP)

A demonstration website created as a final project for the **Web Development 1 (WEB1)** course at the Federal Institute of São Paulo (IFSP).

## Features

- **System Log:** Records script loading status in the console.
- **Destinations Carousel:** Managed slide transitions with manual navigation support.
- **Form Validation:** Prevents submission of empty fields and clears the form after a simulated successful send.
- **Package Details Toggle:** Interactive "show/hide" sections for additional benefits within the `pacotes.html` page.
- **Dynamic Footer Greeting:** Automatically updates the `#footer-msg` content based on the user's current time.

## Quick File Map

- `index.html` — Homepage featuring the hero section and highlights.
- `destinos.html` — Destinations page with the carousel and hotel/itinerary tables.
- `pacotes.html` — Detailed package listings with interactive detail buttons.
- `sobre.html` — Institutional information and "About Us" section.
- `contato.html` — Contact form page.
- `style.css` — All styles, including responsive design via media queries.
- `script.js` — Core logic for the carousel, form validation, and menu toggling.
